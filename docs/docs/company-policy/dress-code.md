# Dress Code

We work in a tech refurbishment and warehouse environment so comfort and function are top priority. Warehouse work can get hot even though we have a temperature controlled environment.

- Prioritize Comfort and Function: The role may involve physical labor (lifting, moving, assembling, or repairing), clothing should allow for easy movement.
- Safety/Warehouse Environment: If working in the warehouse, avoid dangling jewelry or loose clothing that could get caught.
- Clothing Allowed: T-shirts, polos, button-up shirts, blue-jeans, work appropriate shorts (no bicycle or short shorts).
