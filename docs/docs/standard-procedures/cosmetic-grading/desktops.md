# Desktop Grading

**Grade A:** Device may contain light scratching on casing, light wear. Minor dents.<br />
**Grade B:** Scratches and/or missing paint. Some dents. Missing feet pads.<br />
**Grade C:** Major dents, major scratches. Still functional.<br />
**Grade D:** Non-Functional or *functionally defective device.<br />

**Functional Defects**
- ⁠Logic Board Failure
- ⁠Damaged/Defective Ports
- Missing Screws
- ⁠Non-Functioning Audio
- ⁠Non-Functioning Wifi/Network Adapter
