# Standard Operating Procedures

### Cosmetic Grading
Every project comes with a grading requirement for the units. Some will need to be A grade while others will be B or “As Is”. These requirements will be posted with the project details at the start of any project. If uncertain about the requirements or units are not meeting the standards needed, reach out to your supervisor for further instructions.

### Refurbishing
Units will need to be cleaned, configured and a current operating system installed. Configuration will be provided at the start of each project and supplies will be provided by the Project Manager. Some units will need to be skinned to increase quality and cover up blemishes and scratches.

Battery health will be tested for each unit. If battery health is below 60% you will need to replace the battery from another failed unit.

### Final Testing
Units will be tested via our tool ATools. The battery health will be displayed. A keyboard test will be provided and all keys need to be tested. Test WIFI and network adapter. Run device manager to ensure no warnings are shown. If they are shown to continue to run updates, some devices will need updates directly from the manufacturers website. Finally run a virus scan.

### Accurate Documentation
Everything done to a unit needs to be accurately documented in google sheets. You will be provided your own sheet to document each unit in its entirety including any cosmetic damage. Any configuration changes need to be documented as well as skinning.
